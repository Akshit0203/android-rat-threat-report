# Images — Annotated Capability Figures

This folder holds screenshots of the CraxsRAT operator console, included as **capability evidence** for the threat analysis in [`../docs/03-capability-analysis.md`](../docs/03-capability-analysis.md).

They are published under fair-use for educational commentary: the purpose is to show *what the threat can do to a victim* so defenders can recognize and counter it.

- `Connection.png` — C2 connection / device check-in
- `Managers.png` — operator management menu
- `Tools.png` — operator tools menu
- `Screen Mirroring.png` — live screen capture surface
- `Camera manager.png` — remote camera control
- `File Manager.png` — remote filesystem access
- `Applications.png` — installed-app enumeration
- `Monitor.png` — monitoring features
- `Extra.png` — additional features
