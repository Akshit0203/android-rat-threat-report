# References & Further Reading

Authoritative sources for the frameworks, techniques, and defenses referenced in this analysis.

## Frameworks & standards
- MITRE ATT&CK for Mobile — https://attack.mitre.org/matrices/mobile/
- OWASP Mobile Application Security (MAS) project — https://mas.owasp.org/
- OWASP MASVS (Mobile Application Security Verification Standard) — https://mas.owasp.org/MASVS/
- OWASP Mobile Security Testing Guide (MSTG) — https://owasp.org/www-project-mobile-app-security/

## Android platform security
- Android Platform Security Model & docs — https://source.android.com/docs/security
- Accessibility best practices & security notes — https://developer.android.com/guide/topics/ui/accessibility
- Play Integrity API — https://developer.android.com/google/play/integrity
- Google Play Protect — https://developers.google.com/android/play-protect

## Analysis tooling (for isolated labs only)
- MobSF (Mobile Security Framework) — https://github.com/MobSF/Mobile-Security-Framework-MobSF
- jadx — https://github.com/skylot/jadx
- apktool — https://apktool.org/
- androguard — https://github.com/androguard/androguard

## Threat context on Android RATs / stalkerware
- Coalition Against Stalkerware — https://stopstalkerware.org/
- Public vendor threat reports on Android RAT families (SpyNote, Hydra, Cerberus, CraxsRAT) — search current reporting from reputable vendors (e.g., national CERTs, established AV/threat-intel vendors) for up-to-date IOCs.

## Legal / ethics
- Review your jurisdiction's computer-misuse law before handling samples (e.g., U.S. CFAA, UK Computer Misuse Act 1990, India IT Act 2000 §43/§66). Only study material you are lawfully permitted to possess, and never target devices or accounts without explicit written authorization.
